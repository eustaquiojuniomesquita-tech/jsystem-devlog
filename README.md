# jsystem-devlog
## 24/11/2026, dia 1

Hoje comecei o JSystem. Ainda não tem nada de sistema operacional, foi tudo preparação.

Instalei o NASM, o Clang e o QEMU. Os três instalaram certinho, mas o terminal não achava nenhum deles. Descobri que precisava colocar as pastas no PATH, que é a lista de lugares onde o Windows procura os programas. Depois disso funcionou.

Também aprendi o básico do PowerShell e do Git, e escrevi meu primeiro script, o build.ps1. Na primeira vez o Windows bloqueou, porque vem configurado para não rodar scripts, e tive que liberar. Por enquanto ele só mostra a versão das ferramentas e liga o QEMU.

A tela que aparece é a BIOS procurando algo para iniciar e não achando nada. Foi legal ver isso, porque é ali que um dia vai entrar o bootloader que vou escrever.

A próxima etapa é aprender C direito.

English summary: First day of JSystem. I installed NASM, Clang and QEMU, learned some PowerShell and Git basics, and wrote a small build script that starts an empty virtual machine in QEMU. Next step: learning C properly.
